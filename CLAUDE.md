# Portfolio

Personal portfolio for Ugochukwu Okoli. Next.js 16 static export, TypeScript, plain CSS on the
`design-taste-frontend` kit.

- **Read `docs/NEXTJS_GUIDELINES.md` before writing any code** and follow it.
- Design: use the `design-taste-frontend` skill (kind: software). Do not edit `public/assets/` (the kit).
- Facts come from the resume in `src/content`; never invent clients, metrics or quotes.
- Done = `npm run typecheck && npm run lint && npm run build && npm run check`.
